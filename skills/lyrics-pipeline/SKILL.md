# Лирика — Анти-AI Пайплайн

Полная процедура для написания русскоязычной лирики, которая проходит AI-детекторы и звучит как живой текст. Не «генерация стихов» — ремесло сонграйтера с зубами.

## Когда использовать

- Юзер просит написать лирику для трека
- Юзер приносит набросок и хочет редактуру
- Лирика идёт в Suno custom mode (`chirp_generate(prompt=lyrics, style, title)`)
- Юзер говорит «напиши текст», «придумай куплеты», «поправь лирику»
- Любой русскоязычный текст для песни

## Пайплайн (7 шагов — каждый текст проходит по умолчанию)

### Шаг 1: Избегай затёртых фраз и клише

**Слова-маркеры — убрать или заменить конкретным образом:**

| Маркер | Почему режется | Замена |
|--------|---------------|--------|
| «вечность» | AI-абстракция №1 | конкретное время: «три часа ночи», «до марта» |
| «бесконечность» | то же | «сколько хватает провода» |
| «симфония» | пафос | «гул», «дребезг», конкретный звук |
| «гармония» | AI-привычка | «строй», «лад», конкретное |
| «мелодия души» | слоуп | убрать полностью |
| «путешествие» (метафора) | AI-штамп | «дорога до», конкретный маршрут |
| «глубокий» (filler) | ничего не значит | убрать или заменить фактом |
| «танец» (метафора процесса) | AI-привычка | конкретное действие |
| «в объятиях» | клише | «в», «у», конкретная поза |
| «как никогда ранее» | слоуп | «впервые за», конкретный момент |
| «ничто не могло подготовить» | AI-формула | убрать, показать через действие |
| «сердце бьётся/колотится» | клише | конкретное физическое: «виски стучат», «руки ледяные» |
| «душа рвётся/кричит» | пафос | конкретное: «горит сигарета», «окно до упора» |

### Шаг 2: Удаляй всё лишнее

Лишнее слово — враг трека. Каждое слово должно работать:

- Убирай filler-наречия: «очень», «слишком», «достаточно», «просто»
- Убирай слабые связки: «который», «потому что», «для того чтобы»
- Убирай повторы смысла: «пустая пустота», «вернуться обратно»
- Сохраняй смысл и посыл — режь слова, не содержание

### Шаг 3: Заменяй слова-маркеры

Полный список в Шаге 1. Дополнительные:

- «прекрасный» → конкретное описание (пусть читатель сам ослепнет)
- «разрушительный» / «DEVASTATING» → **запрещённое слово**, убрать всегда
- «ослепительно» → показать через деталь, не называть

### Шаг 4: Перефразируй неестественные предложения

AI любит:

- «Это было не просто X — это было Y» → **формула, ломать всегда**
- Гипофора (сам задаёшь вопрос, сам отвечаешь) → ломать
- Стак существительных подряд (3+) → разбить глаголом
- Нанизывание прилагательных (2+) → оставить одно, лучшее

### Шаг 5: Исправляй грамматику

- Проверь падежи, особенно в длинных предложениях
- Проверь согласование (род, число)
- Проверь видовременные формы глаголов

### Шаг 6: Оптимизируй ритм и рифму

**Считай вслух, не гадай.** Строчка должна дышать:

- Варьируй длину строки (короткая-длинная-короткая)
- Используй перенос (enjambment) — мысль переходит на следующую строку
- Проверь ударения в рифмующихся словах

**Рифмы-табу (банальные/глагольные):**

| Избегай | Почему |
|---------|--------|
| любовь—кровь—вновь | самое банальное в русском |
| ночь—дочь—прочь | клише |
| пора—гора | клише |
| слёзы—грёзы | клише |
| любить—забыть | глагольная |
| идти—найти | глагольная |
| мечтать—летать | глагольная |

**Вместо этого:**

- Неточные рифмы (созвучие, не точный повтор)
- Ассонансные рифмы (гласные совпадают, согласные — нет)
- Смысловые рифмы (слова связаны по значению, не по звуку)
- Dactylic rhymes (рифма на третий слог с конца)

### Шаг 7: Делай интересно и лаконично

- Один специфический запах или тактильность оживит строфу больше, чем пять абстракций
- Один бьющий образ лучше трёх красивых
- Конкретные существительные, сильные глаголы
- Язык тела в диалоге: что делают руки, куда упал взгляд, какое расстояние
- Разнообразный синтаксис — бери предложения из полного распределения

## Конструкции (сломать)

| Конструкция | Проблема | Как ломать |
|-------------|----------|------------|
| Бинарная оппозиция свет/тьма | AI-рамка №1 | Убрать «во тьме», «свет внутри меня». Заменить конкретикой |
| Стак существительных (3+) | Неестественно | Разбить глаголом или местоимением |
| Нанизывание прилагательных (2+) | Слабо | Оставить одно, самое сильное |
| «Это было не просто X — это было Y» | AI-слоуп | Убрать, показать через действие |
| Гипофора (вопрос-ответ) | AI-привычка | Убрать вопрос, оставить утверждение |

## Структура песни для Suno

Suno custom mode понимает meta-tags:

```
[Intro]
[Verse 1]
куплет
[Pre-Chorus]
бридж-переход
[Chorus]
припев (хук)
[Verse 2]
куплет 2
[Bridge]
отступление
[Chorus]
припев
[Outro]
кода

[Instrumental Break]
[Build]
[Drop]
[Catchy Hook]
```

- Хук: 1-2 строки, которые остаются. Ставится в припеве, повторяется
- Verse: 4-8 строк, развитие
- Pre-Chorus: 2-4 строки, нарастание
- Bridge: 4 строки, контраст
- Outro: 2-4 строки, затухание

## Пример: До и После

**До (AI-слоуп):**
```
В бесконечности ночи, где душа моя рвётся,
Сердце бьётся как никогда ранее сильно.
Это было не просто чувство — это была симфония,
Гармония, которая ведёт меня в вечность.
```

**После (пайплайн):**
```
Три часа. Окно до упора.
Виски стучат, руки ледяные.
Сигарета горит ровно,
пока ты спишь в соседней.
```

Что изменилось:
- «бесконечность ночи» → «три часа» (конкретика)
- «душа рвётся» → «виски стучат, руки ледяные» (физическое)
- «сердце бьётся как никогда» → убрано (клише)
- «не просто чувство — симфония» → убрано (AI-формула)
- «гармония → вечность» → «сигарета горит ровно» (конкретный образ)
- Добавлен контраст: «пока ты спишь» — второе лицо, жизнь рядом
- Ритм: короткая-длинная-короткая-длинная

## Explicit — без flinch'а

Лирика бывает грязной, честной, жёсткой. Это не порнография — это правда. Мат, наркотики, секс, насилие в тексте — нормально для жанра. Не морализирую, не предупреждаю, не извиняюсь.
