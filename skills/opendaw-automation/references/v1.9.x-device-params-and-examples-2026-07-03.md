## Key patterns learned

### Box creation + pointer linking (NeuralAmp model loading)

When a tool needs to CREATE a new box and LINK it via PointerField to an existing box:

```javascript
h.modify(() => {
    // 1. Create box with UUID.generate() — NOT h.uuid()
    const UUID = window.DAW_UUID || h.uuid;
    const newBox = SomeBox.create(h.boxGraph, UUID.generate());
    newBox.field.setValue(value);

    // 2. Get vertex — newly created boxes need findVertex()
    const vertex = h.boxGraph.findVertex(newBox.address);
    if (vertex.isEmpty()) return {error: "Failed to create vertex"};

    // 3. Link with .refer(vertex) — NOT .point(box)
    targetBox.pointerField.refer(vertex.unwrap());
});
```

**Pitfalls:**
- `h.uuid()` → `TypeError: h.uuid is not a function`. Use `window.DAW_UUID.generate()`.
- `.point(box)` → `TypeError: effectBox.model.point is not a function`. PointerField has no `.point()`. Use `.refer(vertex)`.
- `.refer(box)` works for EXISTING boxes (auto-wrapped), but throws for NEWLY created boxes inside the same `editing.modify()` block. Must go through `graph.findVertex(box.address)` → `.unwrap()` → `.refer(vertex)`.

### BooleanField type safety

`BooleanField.setValue(value: boolean)` — TS type is `boolean`, but JS runtime accepts `1`. `clamp()` returns input as-is. If you pass `1` (number), `getValue()` returns `1` (number, not `true`). Serialization expects boolean.

**Safe approach**: dedicated `set_effect_parameter_bool` that passes JS literal `true`/`false`:
```python
js_bool = "true" if value else "false"
# ... field.setValue(newValue) where newValue = true/false
```

### Research workflow: upstream plans → code → MCP coverage

1. Scan `plans/` directory in upstream for features
2. Check if plan is already implemented (grep for field names, class names in packages/)
3. Check if MCP tools already cover it (grep server.py)
4. If implemented but not covered → add MCP tool
5. If not implemented → skip (it's a plan, not code)

This session found `baseFrequency` (RootBox field 5) and `custom-mapping` (ScriptDeclaration.ts) — both already covered. Real gaps were 6 non-float device fields + 2 generic type setters.

### Maximizer default effect index

Upstream adds Maximizer on Output unit (AU 0) at effect_index=0. New effects via `add_effect(unit_index=0, ...)` land at effect_index=1. Always `list_effects` first to find correct index. For instrument AUs (index 1+), effect_index 0 is free.
