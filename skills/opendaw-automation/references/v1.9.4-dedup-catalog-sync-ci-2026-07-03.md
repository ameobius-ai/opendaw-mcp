## Decision matrix for duplicate removal

When two tools have overlapping functionality:

| Criterion | Question |
|-----------|----------|
| Access pattern | Box-level (richer: fields, pointers) vs adapter-level (thinner)? |
| Return data | Which returns more useful fields? |
| Parameter flexibility | One accepts position OR index, other only index? |
| Output | One returns updated state after mutation? |

Keep the richer tool. Document removal in changelog with reason.

## CI smoke test pitfalls

1. **FastMCP tool names include prefix**: `mcp_opendaw_get_project_info`, NOT bare `get_project_info`
2. **`mcp.list_tools()` is async**: must `asyncio.run(mcp.list_tools())`
3. **Local test first**: always run smoke test locally before pushing — CI environment may differ
