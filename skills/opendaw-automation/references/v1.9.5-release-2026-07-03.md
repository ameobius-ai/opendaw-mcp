## Security audit technique

```python
# For each mcp_opendaw_* function with str params:
# Check if param appears in f-string evaluate() without safe_ prefix or .replace()
for arg in node.args.args:
    if arg.annotation is Name('str'):
        func_text = source[node.lineno-1:node.end_lineno]
        safe = f'safe_{arg.arg}' in func_text or f'{arg.arg}.replace' in func_text
        raw = f'{{{arg.arg}}}' in func_text and not safe
        if raw: issues.append(f"{name}: str param '{arg.arg}' unsanitized")
```

## By-design raw JS params (NOT bugs)

These tools accept raw JavaScript by design — sanitizing would break functionality:
- `add_automation(points)` — raw `[[pos, value], ...]` JS array
- `add_instrument_automation(points)` — same
- `wait_for_condition(condition_js)` — raw JS condition
- `evaluate_raw(script)` — raw JS execution
