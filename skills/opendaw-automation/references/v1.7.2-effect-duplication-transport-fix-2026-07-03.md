### Bug found during testing
`get_effect_chain` returned `type: null` for all effects because it used `constructor.name` (e.g. "CompressorDeviceBox") — the test was checking for `effect_type` key which doesn't exist (the key is `type`). Fixed in v1.7.4: now returns short name via `.replace(/DeviceBox$/, "")`.

## transport(action) bugfix

**Before**: always toggled regardless of `action` parameter:
```js
if (eng.isPlaying?.getValue?.()) { eng.stop(); } else { eng.play(); }
```

**After**: respects action:
```python
act = (action or "toggle").lower().strip()
```
```js
const isPlaying = !!eng.isPlaying?.getValue?.();
if ('{act}' === 'play') { if (!isPlaying) eng.play(); return {status:'playing'}; }
else if ('{act}' === 'stop') { if (isPlaying) eng.stop(); return {status:'stopped'}; }
else { /* toggle */ }
```

This was previously documented as pattern #78 "pre-existing bug, not fixed yet" — now resolved.

## Unused param cleanup

`set_region_duration` and `set_region_mute` both had `region_type: str` parameter that was never referenced in the function body. The code finds regions via `trackBox.regions.pointerHub.incoming()` regardless of type.

**Detection method**: AST parse → for each `@mcp.tool()` function, check if each param name appears in body lines beyond signature. Found 2 unused params.

**Fix**: removed `region_type`, gave `unit_index` a `=0` default for backward compat.
