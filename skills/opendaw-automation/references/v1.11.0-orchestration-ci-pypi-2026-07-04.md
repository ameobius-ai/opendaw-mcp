## CI Threshold Pitfall (CRITICAL)

CI workflow counts tools with:
```python
tools = [n for n in ast.walk(tree) if isinstance(n, ast.AsyncFunctionDef) and n.name.startswith('mcp_opendaw_')]
```

This EXCLUDES `start`, `stop`, `evaluate` (3 non-prefixed async defs).
- Local AST (no prefix filter): 261
- CI (with prefix filter): 258

**ALWAYS set CI threshold to the `mcp_opendaw_`-prefixed count.**

Check locally:
```bash
python3 -c "import ast; tree=ast.parse(open('server.py').read()); tools=[n for n in ast.walk(tree) if isinstance(n, ast.AsyncFunctionDef) and n.name.startswith('mcp_opendaw_')]; print(len(tools))"
```

CI failed when threshold was set to 258 but actual `mcp_opendaw_` count was 257 (before `apply_mix_preset` was added). Fixed by matching threshold to prefix-filtered count.

## Orchestration Tool: apply_mix_preset (v1.11.0)

8th orchestration tool. Batch volume/pan/mute/solo to all AUs from JSON or named preset.

- Named presets: `lofi`, `house`, `balanced`, `wide`
- Custom: `preset='{"0":{"volume_db":-3,"panning":0.0},"1":{"volume_db":-6,"panning":-0.3}}'`
- Uses `h.allAUBoxes()` + `h.modify()` per unit
- Volume uses `au.volume.constraints.valueMapper.mapToNormalized(volDb)` for raw conversion
- Panning uses `au.panning.setValue(panning)` directly
- Mute/solo use optional chaining: `au.mute?.setValue?.(params.mute)`

**Pitfall:** Don't use Python ternary inside JS f-string template. `"{x}" if condition else "y"` becomes literal JS text. Compute the value in Python first, then interpolate: `preset_name = x if condition else "y"` then `preset: "{preset_name}"`.

## Orchestration Tool: automation_sweep (v1.10.1)

7th orchestration tool. Smooth automation ramp with linear/exp/log curves.

- Accepts `parameter_name` (NOT `track_index`) — auto-creates automation track
- Uses `h.api.createAutomationTrack(au, field)` + `h.api.createValueClip(autoTrack, 0, {name})`
- Events created via `ValueEventBox.create()` with `box.interpolation.setValue(1)` for linear
- Curve math: exp uses `(Math.exp(t*3)-1)/(Math.exp(3)-1)`, log uses `Math.log(1+t*(Math.E-1))`
- All values clamped to [0, 1]

## Orchestration Tool: create_song_structure (v1.10.1)

6th orchestration tool. Arrangement markers from JSON.

- Uses `MarkerBox.create()` directly — `p.api.addMarker` does NOT exist
- Same pattern as `add_marker` tool: `box.track.refer(markerTrack.markers)`
- Gets markerTrack via `h.timelineBox?.markerTrack`
- Position in PPQN: `Math.round(position_beats * h.ppqn.Quarter)`
