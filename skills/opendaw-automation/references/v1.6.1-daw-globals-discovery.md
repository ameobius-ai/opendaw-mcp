# v1.6.1 — DAW Globals Discovery + 4 New Tools

## Discovery Method

When upstream is static (no new commits) and all ProjectApi methods are covered, discover new MCP tool opportunities by introspecting DAW globals directly:

```python
# 1. List all DAW_ globals
await bridge.evaluate("""() => Object.keys(window).filter(k => k.startsWith('DAW_')).sort()""")
# → 94 globals

# 2. Deep AU adapter introspection (walk full prototype chain)
await bridge.evaluate("""() => {
    const au = window.DAW_HELPERS.allAUs()[0];
    const props = new Set();
    let obj = au;
    while (obj && obj !== Object.prototype)
        for (const name of Object.getOwnPropertyNames(obj))
            if (!name.startsWith('_') && name !== 'constructor') {
                const desc = Object.getOwnPropertyDescriptor(obj, name);
                if (desc && (desc.get || typeof desc.value === 'function' || typeof desc.value === 'object'))
                    props.add(name);
            }
    return [...props].sort();
}""")
# → 33 props including: minimizedField, auxSends, labeledAudioOutputs, deviceHost
```

## New Tools (211 → 215)

### set_unit_minimized(unit_index, minimized)
- **Field**: `au.minimizedField` — BooleanField (NOT FieldAdapter, no `.field` sub-property)
- **Pitfall**: `au.minimizedField.field.setValue()` crashes — BooleanField has `.setValue()` directly
- **E2E**: old=False → new=True ✅

### list_aux_sends(unit_index)
- **Access**: `au.auxSends.adapters()` — adapter collection on AU
- Read-only listing of sends with level/enabled/label

### capture_realtime(duration_seconds, filename)
- **Function**: `window.DAW_captureRealtime(durationSeconds)` — async, returns AudioData
- **Requires**: engine running (`start_engine()` first)
- Output via `WavFile.encodeFloats(audioData)` → base64 → save to disk

### get_sample_info(sample_uuid)
- **Access**: `window.DAW_sampleManager.getAudioData(uuid)` — async
- **Pitfall**: UUID with `{` breaks JS template literals. Use `json.dumps(safe_uuid)` not raw f-string interpolation
- SampleManager API: `fetch`, `getAudioData`, `getOrCreate`, `invalidate`, `record`, `register`, `remove`

## Duplicate tool pitfall

When adding new tools, ALWAYS `grep -n "async def mcp_opendaw_<name>" server.py` first. FastMCP logs WARNING but does NOT prevent duplicate registration — second definition silently shadows first. Found when v1.6.1 re-added start_engine/stop_engine that already existed at line 1262.
